# \# Novel View Synthesis with 3D Gaussian Splatting

# 

# A mini-project exploring novel-view synthesis using 3D Gaussian

# Splatting.

# 

# The project reconstructs a 3D scene from multi-view images and

# renders previously unseen camera viewpoints.

# 

# \## Goals

# 

# \- Reconstruct a real-world scene from multi-view images

# \- Understand the 3D Gaussian Splatting pipeline

# \- Render novel camera viewpoints

# \- Evaluate novel views using held-out images

# \- Generate a camera trajectory through the reconstructed scene
